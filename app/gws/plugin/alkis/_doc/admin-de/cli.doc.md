# Kommandozeilen-Befehl "alkis" :/admin-de/konfiguration/cli/alkis

Die Befehlsgruppe `alkis` verwaltet den ALKIS-Index und den Datenexport. Mit `gws alkis index` erstellen Sie den Index aus den Quelldaten, mit `gws alkis status` prüfen Sie dessen Zustand und mit `gws alkis export` geben Sie ALKIS-Daten aus. Die Befehle rufen Sie im Container auf, zum Beispiel `docker exec -it <container_name> gws alkis index`.
