# Metadaten & INSPIRE :/admin-de/themen/publishing/metadaten

Metadaten beschreiben die Daten eines Projekts – Titel, Zusammenfassung, Kontakt, Schlagwörter und weitere Angaben. Sie lassen sich für Projekte, Layer und Dienste hinterlegen und fließen an mehreren Stellen zusammen: Im Client speisen sie etwa die Attributionsleiste, in den OWS-Diensten die Capabilities-Dokumente. Dabei ergänzen und präzisieren die Projektangaben die des Dienstes.

Für europäische Geodatendienste unterstützt die WebSuite die INSPIRE-Vorgaben. Auf Wunsch enthalten die Capabilities einen INSPIRE-konformen Metadatenblock. Eine Harmonisierung der Sachdaten erreichen Sie, indem Sie für die FeatureInfo-Antworten eigene Vorlagen bereitstellen, die aus den Quellattributen eine INSPIRE-konforme Struktur erzeugen.
