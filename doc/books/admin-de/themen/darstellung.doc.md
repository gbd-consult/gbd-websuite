# Darstellung & Interaktion :/admin-de/themen/darstellung

Dieses Kapitel behandelt den Client und die Präsentation: die Oberfläche, Vorlagen, die Suche, das Drucken und die Datenablage.

Der Client ist die JavaScript-Anwendung, mit der Nutzer die Karte im Browser bedienen. Über eine Liste von Elementen bestimmen Sie, welche Bausteine seiner Oberfläche erscheinen – Ebenenbaum, Suche, Werkzeuge – und für welche Rollen sie sichtbar sind. Was dabei an Text und HTML ausgegeben wird, erzeugen Vorlagen; sie bestimmen etwa den Inhalt eines Feature-Pop-ups oder das Aussehen der Startseite.

Die übrigen Themen beschreiben Funktionen, die der Client beim Server abruft: die einheitliche Suche über Raum- und Sachdaten, die Erzeugung von PDF-Dokumenten und die serverseitige Ablage der Objekte, die Nutzer im Client selbst anlegen.
