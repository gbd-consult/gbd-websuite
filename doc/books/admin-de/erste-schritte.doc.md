# Erste Schritte :/admin-de/erste-schritte

Dieses Kapitel bringt Sie von der ersten Container-Instanz bis zu einem eigenen, lauffähigen Projekt mit Karte.

Der [](/admin-de/erste-schritte/schnellstart) zeigt in wenigen Minuten, wie Sie die WebSuite mit ihrer eingebauten Demo-Konfiguration starten und anschließend eigene Verzeichnisse einbinden. Die [](/admin-de/erste-schritte/installation) beschreibt darauf aufbauend eine Produktivumgebung: HTTPS, QGIS-Server, Datenbank und Server-Einstellungen.

Die [](/admin-de/erste-schritte/konfigurationsgrundlagen) erklären Syntax und Aufbau der Konfigurationsdateien, das [](/admin-de/erste-schritte/einfaches-projekt) wendet beides an. Danach sind Sie so weit, dass Sie die einzelnen Bausteine gezielt unter [](/admin-de/themen) nachschlagen können.
