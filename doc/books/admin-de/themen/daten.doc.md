# Daten & Objekte :/admin-de/themen/daten

Dieses Kapitel behandelt die Sachdaten der GBD WebSuite: Features und Modelle, die Datenbankanbindung und das Editieren.

Der zentrale Begriff ist das *Feature* – ein einzelnes Geoobjekt aus einer Geometrie und einer Reihe von Attributen. Features entstehen zur Laufzeit und sind selbst nicht Teil der Konfiguration; konfiguriert wird stattdessen das *Modell*, das beschreibt, welche Attribute ein Feature besitzt und wie es sich verhält.

Das Kapitel führt zunächst beide Begriffe ein und beschreibt dann den inneren Aufbau eines Modells: Felder, Wertquellen, Validatoren, Widgets und Beziehungen zu anderen Modellen. Es folgt die Anbindung von PostgreSQL/PostGIS als wichtigster Datenquelle. Zum Schluss geht es um das Editieren – wie Nutzer im Client Objekte anlegen, ändern und löschen und wie Sie steuern, wer das darf.
