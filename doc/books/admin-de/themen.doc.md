# Themen :/admin-de/themen

Dieses Kapitel erklärt die Bausteine der GBD WebSuite und ihr Zusammenspiel: was ein Layer, ein Modell oder eine Aktion ist, wofür Sie sie einsetzen und worauf Sie bei der Konfiguration achten müssen.

Die Darstellung ist bewusst auswählend. Sie beschreibt die Konzepte und die wichtigsten Einstellungen, nicht jede einzelne Eigenschaft – diese führt die [](/admin-de/konfiguration) vollständig auf. Jedes Thema verweist am Ende auf die zugehörigen Konfigurationsobjekte.

Die Kapitel bauen lose aufeinander auf: [](/admin-de/themen/grundlagen) beschreibt das Fundament, die übrigen behandeln je einen Funktionsbereich und lassen sich einzeln lesen. [](/admin-de/themen/datenquellen) gibt einen Überblick, woher die Daten überhaupt stammen können; [](/admin-de/themen/qgis) fasst zusammen, an welchen Stellen QGIS-Projekte ins Spiel kommen.
