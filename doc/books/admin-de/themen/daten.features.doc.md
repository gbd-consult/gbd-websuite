# Features & Modelle :/admin-de/themen/daten/features

Ein *Feature* ist ein einzelnes Geoobjekt aus einer Geometrie und einer Reihe von Attributen. Features entstehen zur Laufzeit – aus Vektorlayern, Suchergebnissen oder beim Editieren – und sind selbst nicht Teil der Konfiguration. Konfigurierbar ist stattdessen das *Modell*, das beschreibt, wie ein Feature aussieht und sich verhält.

Ein Modell legt fest, welche Attribute ein Feature besitzt: Jedes Attribut entspricht einem *Feld* des Modells. Darüber hinaus kann ein Modell Beziehungen zu anderen Modellen definieren und so zusammengehörige Objekte verknüpfen, wodurch sich auch komplexere Datenstrukturen abbilden lassen.
