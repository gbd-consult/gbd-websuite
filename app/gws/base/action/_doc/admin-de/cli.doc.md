# Kommandozeilen-Befehl "action" :/admin-de/konfiguration/cli/action

Die Befehlsgruppe `action` ruft eine Server-Aktion unmittelbar von der Kommandozeile auf – vor allem zur Fehlersuche.

`gws action invoke --cmd <Befehl> --params <JSON>` führt eine Aktion aus. `gws action profile --cmd <Befehl> --params <JSON>` tut dasselbe und zeichnet dabei ein Laufzeitprofil auf, das im veränderlichen Datenverzeichnis abgelegt wird.
