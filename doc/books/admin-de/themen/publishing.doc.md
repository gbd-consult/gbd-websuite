# Datenveröffentlichung :/admin-de/themen/publishing

Dieses Kapitel behandelt, wie die GBD WebSuite ihre Daten für andere Systeme bereitstellt: über standardisierte OGC-Webdienste, deren Metadaten sowie den Export von Features in Dateiformate.

Die WebSuite ist nicht nur Client fremder Dienste, sondern zugleich Server: Dieselben Projekte, die sie im Browser darstellt, kann sie als WMS, WMTS, WFS oder CSW veröffentlichen, sodass Desktop-GIS und andere Anwendungen unmittelbar darauf zugreifen. Dabei greifen dieselben Berechtigungen wie im Client, sodass sich Dienste auf bestimmte Rollen einschränken lassen.

Beschreibende Angaben zu Projekten, Layern und Diensten pflegen Sie als Metadaten; sie fließen in die Capabilities-Dokumente der Dienste ein und lassen sich INSPIRE-konform ausgeben. Unabhängig davon können Nutzer einzelne Features herunterladen – der Export wandelt sie in Formate wie CSV, GeoJSON oder Shapefile um.
